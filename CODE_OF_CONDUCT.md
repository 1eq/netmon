# Code of conduct

NetMon follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful, assume good faith, and keep discussion about the work.

To report a comment, issue or pull request, use GitHub's **Report content** option in its `…` menu and choose to report it to the repository maintainers. The maintainers will review every report and act on it as the Covenant describes.
